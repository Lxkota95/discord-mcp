# Hints — milestone 3

Read one hint, then go back and try again.

## Hint 1 (nudge)

Order matters in `request`:
1. `initialize`? → legacy handshake (and remember you're in legacy mode)
2. already in legacy mode? → legacy methods (`ping`), else method not found
3. modern: read the version → missing? unsupported? → errors
4. modern methods (`server/discover`), else method not found

## Hint 2 (stronger)

- Destructure the request to own its parts: `let Request { id, method, params } = request;`
- Reading the version with plain `get`s:
  ```rust
  let requested = params
      .as_ref()
      .and_then(|p| p.get("_meta"))
      .and_then(|meta| meta.get(META_PROTOCOL_VERSION))
      .and_then(Value::as_str);
  ```
- The `-32022` error: `ErrorObject::new(UNSUPPORTED_PROTOCOL_VERSION, "Unsupported protocol version").with_data(json!({ "supported": [MODERN_VERSION, LEGACY_VERSION], "requested": requested }))`
- A `json!` object can use a constant as a key: `json!({ META_SERVER_INFO: { … } })`.

## Hint 3 (almost the answer)

`handle_line`:

```rust
match jsonrpc::parse(line) {
    Ok(message) => self.handle(message).map(|response| response.to_line()),
    Err(response) => Some(response.to_line()),
}
```

`main`:

```rust
let mut server = Server::new(ServerInfo {
    name: env!("CARGO_PKG_NAME").to_owned(),
    version: env!("CARGO_PKG_VERSION").to_owned(),
});
run_lines(io::stdin().lock(), io::stdout().lock(), |line| server.handle_line(line))
```

`main` returns `io::Result<()>` so the `?`-free last line can be the return value. The closure
borrows `server` mutably: that's why `run_lines` takes `FnMut`.
