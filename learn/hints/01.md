# Hints — milestone 1

Read one hint, then go back and try again.

## Hint 1 (nudge)

The whole function is a loop over `input.lines()`. Each item is an `io::Result<String>`: unwrap it
with `?`. Then decide: skip it, call `handle`, write the reply.

## Hint 2 (stronger)

- `lines()` already removes `\n` *and* `\r\n`, so the CRLF test passes once you use it.
- "Blank" includes `"   "`: `line.trim().is_empty()`.
- `if let Some(reply) = handle(&line) { … }` handles the `None` case for free.
- `writeln!(output, "{reply}")?;` then `output.flush()?;`.

## Hint 3 (almost the answer)

Check the reply before writing:

```rust
if reply.contains('\n') {
    return Err(io::Error::new(io::ErrorKind::InvalidData, "a reply must be a single line"));
}
```

The signature already declares `mut output: W`, so you can write to it. The function ends with
`Ok(())` after the loop.
